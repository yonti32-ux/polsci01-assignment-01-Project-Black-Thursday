1. Extract ALL files from this ZIP into one folder on your computer.

2. Open that extracted folder.

4. Your browser should open http://127.0.0.1:8000/
5. Keep the terminal window open while presenting; close it afterward.

- Port 8000 is used: close the existing server before launching again.
- File missing: confirm you extracted the entire COMPLETE ZIP, not
  only Black_Thursday_v04_Selective_Update.zip.

  for the local launcher and server is included for inspection.
